# Exact bill optimum with assumed PV, export price and battery (ceiling for S1 and S2)

Generated by `swiss/experiments/oracle_pvbat.py` from `swiss/experiments/oracle_results/oracle_pvbat.json`. Nothing here is typed by hand.

Scenarios: **S1** = Phase A district + assumed PV (M-003, A-011 to A-014) + assumed export price (A-015); **S2** = S1 + assumed battery per building (M-004, A-016, A-017). Both describe a district with assumed equipment, not the real houses. The program is a linear program per building with perfect foresight (tanks, battery, import and export in one year); the bill is import cost minus export revenue. Not covered: peak and ramp reward terms, forecast error.

## How to read it
- The ceilings are exact for this simulator and its assumptions; PV, export price and battery are assumptions (A-011 to A-017), so these numbers describe the assumed scenario.
- The saving share is relative to the zero-action bill of the same scenario.
