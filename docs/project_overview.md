# Project overview

Swiss residential district energy simulation on CityLearn 3.3.0 (plan: `master_plan.md`; progress: `execution_log.md`). Phase A (Swiss heating baseline, hourly, six buildings) is approved (2026-11-18, D-031). Phase B (assumed PV, battery, export price, RC thermal model, scenario tariffs, 15-minute environment, LEG and EV scenarios, exact ceilings, RL on the cluster, and the receding-horizon MPC study) is implemented and awaits the owner's approval (`phases/phase_b_completion_report.md`). Phase C (future climate from CH2025, cooling in two system archetypes, adoption levels, scenario matrix, climate impact analysis, dashboard pages) was authorised by the owner's chat instruction of 2026-11-19 (D-048) and is implemented, including the completion report and the room-unit archetype; it was approved at the phase gate on 2026-11-20 (D-056; `phases/phase_c_completion_report.md`, proposal `phases/phase_c_proposal_updated.md`). The Phase B gate has no recorded decision.
The district is a **constructed composite** of three single-family houses (HEAPO) and three multi-family heat pumps (ETH/EKZ), simulation year 2023, with measured heat-pump electricity, derived thermal demand, synthetic thermal tanks, KLO weather, the EKZ standard tariff and a modeled carbon-intensity series; Phases B and C add assumed PV, battery, export price, an RC thermal model, scenario weather (CH2025 delta change) and modeled cooling. See `phases/phase_a_completion_report.md` and `phases/phase_b_completion_report.md`.
Layout: `swiss/` (code, tests, datasets), `data/` (raw ignored, interim, canonical), `docs/` (audit trail), `web/` (dashboard), `my_data/` (earlier US-cooling experiments, unchanged).
